📝 Summary of Fix

Root Cause: The batchPrintUnprinted() function was calling generateCheckHtml() which created a simplified HTML version with hardcoded styling. Single print used the actual DOM template with proper rendering.

Solution: Created generatePrintableCheckHtml() that applies the same template logic as single print, ensuring identical output for both batch and single printing.

Result: Batch printing now produces checks that are pixel-perfect matches to single print, with proper templates, MICR line, stubs, and all formatting.

Additional Improvements

  • Error Handling: Print window opens synchronously before database operations to prevent iOS Safari popup blocking
  • User Feedback: Clear error messages shown when printing fails or popup is blocked
  • Approval Workflow: Pending checks now show status badges, with Approve/Reject buttons for approvers and admins
  • Smart Batch Printing: Batch print now skips pending checks instead of disabling entirely, printing only approved checks
